{{/* Series navigation. Call with: (dict "page" . "mode" "header") → "Part N of M in " line (dict "page" . "mode" "nav") → previous/next links within the series Part numbers are derived from date order inside the series, never hand-written, so inserting a post mid-series renumbers everything downstream automatically. A page with no series (or a series with no term page) renders nothing. Series that number themselves from zero (Primal Chase opens with "Part 0") set `series_start: 0` in their content/series//_index.md. That is one value per series, not a number per post, so the auto-renumbering above still holds — it just shifts where counting begins so the badge agrees with the titles the posts already carry. */}} {{ $page := .page }} {{ $mode := .mode | default "header" }} {{ with $page.GetTerms "series" }} {{ $term := index . 0 }} {{ $ordered := $term.Pages.ByDate }} {{ $total := len $ordered }} {{/* isset, not `default` — series_start is legitimately 0, which `default` treats as empty */}} {{ $start := 1 }} {{ if isset $term.Params "series_start" }}{{ $start = $term.Params.series_start }}{{ end }} {{ $idx := -1 }} {{ range $i, $p := $ordered }} {{ if eq $p.RelPermalink $page.RelPermalink }}{{ $idx = $i }}{{ end }} {{ end }} {{ if ge $idx 0 }} {{ if eq $mode "header" }}

Part {{ add $idx $start }} of {{ $total }} in {{ $term.LinkTitle }}

{{ else }} {{/* cond evaluates both branches, so build these with if to avoid indexing past the ends */}} {{ $prev := false }} {{ if gt $idx 0 }}{{ $prev = index $ordered (sub $idx 1) }}{{ end }} {{ $next := false }} {{ if lt $idx (sub $total 1) }}{{ $next = index $ordered (add $idx 1) }}{{ end }} {{ if or $prev $next }}

More in {{ $term.LinkTitle }}

{{ end }} {{ end }} {{ end }} {{ end }}
